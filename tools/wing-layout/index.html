CAD handoff and provenance

Save project preserves station inputs, profiles and provenance. CAD sections JSON exports both wing halves as polygon sections in millimeters. Use the included Rust exporter to loft these sections and write STEP and BREP.

Sections share cosine sampling and are closed at the trailing-edge midpoint for lofting. The actual OCCT loft is interpolated between sections; verify the exported shape before designing ribs, spars or molds.

Historical reference: Smithsonian Ho 229 V3 preservation project. Exact section coordinates and twist remain unverified in this example.
